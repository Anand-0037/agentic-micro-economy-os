## Now — Verifiable cycle on Mantle Sepolia

- Full observe → plan → guard → act → log loop
- Narrative Console with nine-node replay
- `MantleAgentIdentity` + `DecisionLogged` on testnet
- Optional [0G Storage](/glossary#0g-storage) reasoning anchors
- LLM provider fallback chain with `local_rules` safety default

## Next — Production hardening

- Mantle mainnet deployment with verified contracts
- MPC / KMS signing instead of hot EOAs
- Multi-agent coordination (shared policy registry, isolated identities)
- Enhanced eval harness (`/api/eval-report`) for decision quality metrics
- Rate limiting + auth on operator endpoints

## Later — Cross-ecosystem proof

- Cross-chain proof commitments (bridge-aware decision logs)
- Formal verification of core policy predicates
- Third-party auditor tooling (export bundles, batch replay)
- Plugin SDK for custom execution adapters beyond Mantle DEX

Contributions welcome via GitHub issues and PRs on the open-source codebase.
